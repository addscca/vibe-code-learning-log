# Vibe Code 从零开始的学习日志

一个完全零基础的人，如何用 Vibe Coding 从 0 做出真实上线的产品。

这里记录的不是教程里的"标准答案"，而是一个真实学习者的完整过程：包括走对的每一步，也包括踩过的每一个坑。

## 这是什么

Vibe Coding（氛围编程）是指用自然语言和 AI 协作，把想法直接变成能用的产品。你不需要先学会写代码，你需要的是：一个想法、把想法说清楚的能力，以及愿意不断和 AI 来回打磨的耐心。

这个仓库是我从零开始的公开学习日志。如果我也能从一个想法做到产品上线，你应该也可以。

## 适合谁

- 完全没写过代码，但想做出自己产品的人
- 有想法、想低成本验证的人
- 对 AI 编程好奇，但不知道从哪里开始的人

## 怎么用

1. 按顺序读 `docs/` 下的三篇，先建立整体认知。
2. 跟着 `01` 里的最小任务，自己动手做一次。
3. 看 `02` 的真实案例，理解一个完整产品是怎么长出来的。
4. 用 `journal/` 里的模板，开始记录你自己的每一天。

我一开始也以为"做产品"必须会编程。后来发现，挡住大多数人的不是技术，是"觉得自己不行"。如果你也有一个想做的东西，就从今天开始。
