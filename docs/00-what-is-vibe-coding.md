# 00 · 什么是 Vibe Coding

## 一句话理解

Vibe Coding 是"氛围编程"：你不用先懂编程语言，而是用大白话把想法告诉 AI，让 AI 帮你把代码写出来，你再对着做出来的东西提意见，来回改，直到它变成你想要的样子。

它更接近"产品思维 + 沟通能力"，而不是"写代码能力"。

## 和传统编程的区别

| | 传统编程 | Vibe Coding |
|---|---|---|
| 起点 | 先学语法、数据结构 | 先有一个想法 |
| 方式 | 自己一行行写 | 用自然语言和 AI 对话 |
| 核心能力 | 记 API、写逻辑 | 描述需求、验收结果 |
| 速度 | 慢，但每一步都懂 | 快，但要学会检查和追问 |

## 为什么零基础也能做

因为 AI 已经把"写代码"这件事的成本降到了很低。你真正要做的是三件事：

1. **说清楚**：你想要什么，越具体越好。
2. **会验收**：AI 做出来的对不对，符不符合你要的。
3. **能坚持**：第一版一定不完美，靠一次次修改逼近目标。

## 三个常见的误区

### 误区一："用了 AI 就不用学习"

错。Vibe Coding 不是不用学，而是把学习从"背语法"变成"懂产品、懂流程、会判断"。你会慢慢认识文件、接口、部署这些概念，只是不用一开始就啃书。

### 误区二："AI 说的都对"

错。AI 会犯错，会过度设计，也会理解错你的意思。每次改完，一定要自己点开看看，用"这是我要的吗"来验收。

### 误区三："第一版就要完美"

错。先让它能跑起来，再慢慢打磨。能用的粗糙版本，远胜过永远做不完的完美版本。

## 一个最小的心智模型

把 AI 当作一个"干活很快、但不完全懂你的实习生"：

- 你负责：定方向、说需求、验收、做决定。
- AI 负责：写代码、改代码、解释它做了什么。

方向永远是你来定，这也是为什么"想法"比"技术"更重要。
