# 02 · 实战复盘：从一句想法到上线「此刻回信」

这是我从零开始、用 Vibe Coding 做出的第一个真实上线产品。把它完整记下来，作为这个日志的第一个实战样本。

## 它是什么

「此刻回信」：深夜说不出口的话，写一句，另一个时空的你，替你接住。

面向大学生深夜情绪场景：用户写下一句此刻的真实感受，AI 以「另一个时空的你」身份回信——会撒娇、会嘴硬心软，但最后一定接住你。回复可以一键生成水墨/霓虹卡片，保存到相册、分享到朋友圈，分享卡底部的二维码再把新朋友带回产品。

- 线上地址：https://huixin-app.sealoshzh.site
- 开源仓库：https://github.com/addscca/huixin-app

## 起点：想法是怎么收敛的

一开始的想法是"互动测试 + AI 形象卡"。但很快被自己否掉：标签过时、无法真正共情。

反复打磨后，方向收敛成一句话：**戳中大学生情感需求**。不做功能测试，做"写一句真实感受，然后被接住"。

这里有个最重要的经验：**先想清楚"用户为什么需要它"，再决定"它长什么样"。**

## 几个关键决策

1. **先是产品，再是中国风。** 中国风是皮肤，不是内核。先确认产品立得住，再谈风格。
2. **戳情绪，不堆功能。** 产品形态可以极简，但情绪要准。
3. **AI 要有"人味"。** 参考了做得好的 AI 陪伴产品：会撒娇、假装生气、嘴硬心软，表达带情绪化烙印，而不是客服式安慰。
4. **先做短期的最小闭环，不做长期社交。** 先把"存相册顺手、访问不麻烦"做扎实，再想别的。

## 核心循环

```
写一句 → AI 回信 → 生成卡片 → 存相册 → 分享 → 二维码回流
```

整个产品就是这一个循环，没有多余功能。极简，反而更容易跑通。

## 技术栈（零基础也能看懂版）

- **Next.js + TypeScript**：做网页应用的主流框架（AI 推荐的，我照做）。
- **DeepSeek API**：让 AI 回信的"大脑"，一个接口调用。
- **Canvas**：在网页里把文字画成卡片图片。
- **Web Share API**：手机上"保存到相册"用到的浏览器能力。
- **Sealos**：把产品部署到网上、让所有人都能访问的平台。

对零基础来说，不需要提前学会这些名字。跟着 AI 走，做一次就认识了。

## 迭代记录

- **v1**：MVP。写一句 → 回信 → 卡片下载。
- **v2**：图片改为「保存到相册」；加 PWA，手机访问更顺手。
- **v3**：分享卡底部加二维码，扫码回流。
- **v4**：二维码下加戳人文案。
- **v5**：二维码放大、文案收敛。

每版只改一两处，改完就上线验证。**小步迭代**在这里体现得最明显。

## 踩过的坑（新手都会遇到）

1. **GitHub 登录一直闪退**：注册/登录阶段反复失败，卡了很久。换网络、多试、最终改走其他部署平台绕过去。别被第一道坎劝退。
2. **部署平台欠费，服务突然停掉**：产品刚上线就遭遇平台暂停。教训：留意账户余额，重要产品要有备份方案。
3. **"保存图片"体验不好**：最初是下载文件模式，手机用户嫌麻烦。改成调用系统"保存到相册"，顺手很多。用户体验的小细节，往往决定产品是否被接受。

## 能迁移的经验

- 想法比技术重要，先想清楚为谁解决什么问题。
- 第一版只做核心循环，其他都是以后的事。
- 每步只改一点，改完立刻验证。
- 卡住时，把报错和上下文完整丢给 AI，多问一次。
- 把过程记录下来——你现在看到的这份日志，就是由此而来。
