# 01 · 零基础起步：工具与心态

## 你需要准备三样东西

1. **一个 AI 编程助手**：比如 Codex、Claude Code、Cursor 等。它负责写代码。
2. **一个 GitHub 账号**：用来存代码、记录进度、公开分享你的成果。注册在 https://github.com。
3. **一个想法**：哪怕很小。没有想法，工具再好也没用。

> 如果注册或登录 GitHub 时遇到卡顿、闪退，多试几次、换个网络或浏览器，这是很多新手都会遇到的第一道坎，别被它劝退。

## 第一次对话怎么写

和 AI 说话不需要术语，但要具体。一个有用的句式：

> "我想做一个……（什么产品），给……（谁）用，它要能……（核心功能）。先帮我做一个能打开的最简单版本。"

把"谁用、用来干嘛、第一步先做什么"说清楚，AI 更容易一次做对。

## 最小任务：做一个能打开的小页面

不要一上来就做复杂产品。先完成这个 10 分钟任务，建立信心：

1. 让 AI 新建一个最简单的网页项目。
2. 页面里写一句话："这是我用 Vibe Coding 做的第一个页面。"
3. 在本地把它跑起来，用浏览器打开看到这句话。
4. 让它改：换个背景色、改个字体、加个按钮。

做完这四步，你已经走通了"提出需求 → AI 实现 → 验收 → 再改"的完整循环。后面做任何大产品，本质都是这个循环的放大。

## 遇到报错怎么办

新手最怕报错，但报错是常态，不是失败。

1. 不要慌，把报错信息**原样复制**给 AI。
2. 加上一句："我做了什么操作，出现了这个报错，帮我看看哪里出问题，并解释原因。"
3. AI 会给你修改方案。改完再试一次。
4. 如果还不行，把新的报错再发过去，继续循环。

大多数"卡住"，其实只是"多问一次"的事。

## 新手最该有的三个心态

- **先跑通，再完美**：先让它能用，再谈好看。
- **小步走**：每步只做一个改动，好验收也好回退。
- **把过程记下来**：这正是这个日志存在的意义——你的每一步都算数。
